# Olympic-Sports-Performance-Analysis
Tableau Public Dashboard 
[Tableau Public Dashboard Link Here](https://public.tableau.com/en-us/gallery)

## Project Overview
This project analyzes the performance of athletes and countries in the Olympic Games using data visualization tools.

## Features & Insights
- Analysis of medal tallies by country and year.
- Performance comparison across different sports categories.
- Demographic distribution (age, gender, height/weight) of atheletes.
- Insights into top-performing teams and individuals.

## Tools Used
- **Data Analysis & Visualization:** Tableau
- **Documentation:** Markdown / GitHub
